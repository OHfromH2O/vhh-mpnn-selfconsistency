## 재설계 영역 정의 (원문 프로토콜에서 변경함)

본 산출물은 §3.2의 CDR 정의를 그대로 쓰지 않았습니다. 변경 내용과 사유를 아래에 밝힙니다.

| 항목 | 내용 |
|---|---|
| 원문 규정 | ANARCI(IMGT)로 CDR1/2/3. 불가 시 항원과 4.5 Å 이내 인터페이스 잔기로 대체 |
| 실제 적용 | **인터페이스(4.5 Å) ∪ CDR3** |
| ANARCI 사용 | 아니오 (미설치) |
| CDR3 경계 산출 | 모티프 regex (FR3 Y[YFHVAIL]C ... FR4 W[GA][QRKPAE]G[TAS]) |
| CDR3 구간 | 100–118 (1-based, 설계 사슬 A) |

### 왜 바꿨는가

타깃 8YVJ의 항원 접촉 잔기는 CDR3에 단 1개만 분포합니다
(전체 접촉 16잔기). 원문의 대체 경로인 인터페이스 정의만 적용하면
M2(CDR 한정 모드)가 항체 결합 특이성을 좌우하는 CDR3를 거의 재설계하지 않게 되어,
M1 대 M2 비교가 "CDR 한정 설계"가 아니라 "접촉면 한정 설계"가 됩니다.
JD의 항체 디자인 축과 어긋나므로 CDR3 전체를 합집합으로 포함했습니다.

### 이 정의의 한계

1. IMGT CDR1/CDR2 **전체를 포함하지 않습니다.** 두 루프에서는 접촉 잔기만 들어갑니다.
   따라서 정통 CDR 정의와 동일하지 않으며, M2를 "CDR 재설계"로 부르는 것은 부정확합니다.
2. CDR3 경계를 ANARCI가 아닌 서열 모티프로 잡은 경우 numbering scheme 검증을 거치지 않았습니다.
3. 재설계 영역 크기(34/129 잔기)가 정의에 따라 달라지므로,
   M1(전체 129잔기)과의 비교는 설계 자유도가 다른 조건 간 비교입니다.

### 재설계 영역 (1-based, 설계 사슬 A)

```
............................RHIPGSV....................IGD................Q.SAAN...................AAARGLSDWTCSFESGVNS...........
                            iiiiiii                    iii                i iiii                   3333333333333333333           
   (i = 항원 접촉, 3 = CDR3)
```

접촉만: [29, 30, 31, 32, 33, 34, 35, 56, 57, 58, 75, 77, 78, 79, 80]
CDR3만: [100, 101, 102, 103, 104, 105, 106, 107, 109, 110, 111, 112, 113, 114, 115, 116, 117, 118]
양쪽:   [108]

### 이황화결합 주의

재설계 영역에 Cys [110]가 포함됩니다(사슬 전체 Cys: [25, 36, 99, 110]).
나노바디는 CDR1–CDR3를 잇는 추가 이황화결합을 갖는 경우가 많으므로,
설계 서열이 이 위치를 보존하지 못하면 구조가 달라질 수 있습니다.
보존율은 `work/04_metrics/cys_retention.csv`에 집계됩니다.
